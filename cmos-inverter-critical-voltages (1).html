01 — THE VOLTAGE TRANSFER CHARACTERISTIC

One curve, five numbers, every logic gate built since

Every CMOS inverter has a voltage transfer characteristic, or VTC: a plot of output voltage against input voltage. It looks like a single smooth drop from high to low, but that drop hides five specific voltages that every digital IC datasheet depends on.

Illustrative VTC for V_DD = 5 V. Exact positions shift with transistor sizing and process. Tap a point to jump to its definition below.

Near the two ends of the curve, the inverter behaves the way a logic gate is supposed to: a low input gives a firmly high output, and a high input gives a firmly low output. In between lies a narrow transition region, where the output is neither clean logic level. That transition region is where the five critical voltages are defined.

Two of them describe the output the gate can guarantee. Two describe the input the gate can still interpret correctly. The fifth marks the exact point where the curve crosses itself — input equals output.

02 — THE FIVE CRITICAL VOLTAGES

What each one actually guarantees

VOH
Output HighMinimum guaranteed output for logic 1
With input held low, the PMOS transistor is fully on and the NMOS is fully off, pulling the output to a level the next gate will always read as a 1. VOH is the floor of that region — it never drops below this value while the input stays low.
VOL
Output LowMaximum guaranteed output for logic 0
With input held high, the NMOS pulls hard and the PMOS is off, so the output settles near ground. VOL is the ceiling of that region — the output never rises above it while the input stays high.
VIH
Input HighMinimum input still read as logic 1
Defined as the input voltage where the slope of the VTC equals −1, on the low-input side is not right — VIH sits on the high side: any input at or above it is still interpreted as a solid 1, even though the output has already started to fall.
VIL
Input LowMaximum input still read as logic 0
The other point where the VTC slope equals −1, but on the low-input side. Any input at or below it is still safely interpreted as a 0, even though the output has begun to droop from VOH.
VM
Switching ThresholdWhere V_out = V_in
The single point where the curve crosses the line Vout = Vin. It marks the input voltage at which the gate itself is undecided, and it is set almost entirely by the relative drive strength of the PMOS and NMOS — their width-to-length ratios.
SWITCHING THRESHOLD, MATCHED INVERTER (k_n = k_p) V_M = V_DD / 2

Real inverters rarely land exactly there, because electrons move faster than holes. Designers compensate by widening the PMOS relative to the NMOS — typically by a factor of two to three — to pull VM back toward the midpoint.

03 — NOISE MARGINS

The gap between "guaranteed" and "misread"

The four outer voltages combine into two numbers that matter more than any of them alone: how much a signal can be corrupted before a gate reads it wrong.

NOISE MARGIN, HIGH NM_H = V_OH − V_IH
NOISE MARGIN, LOW NM_L = V_IL − V_OL
HIGH MARGIN
LOW MARGIN

A driving gate's output has to survive a trip down a wire — resistance, capacitive coupling from a neighboring line, a bounce on the ground rail — before it reaches the next gate's input. As long as the corruption stays inside the noise margin, the receiving gate still reads the correct logic level. Once it doesn't, a 1 can arrive looking like a 0, and the error propagates through everything downstream.

04 — WHY THIS MATTERS IN PRACTICE

Five voltages, whole-chip consequences

A

Sizing decisions trace back here

A designer choosing transistor widths is really choosing where VM sits and how wide the noise margins are — the two things these five voltages exist to describe.

B

Cascaded gates compound small errors

A chip is millions of inverting stages in series. If each one shaves a little off the noise margin, the last gate in a long chain sees almost none of it left.

C

Scaling squeezes the margins

As supply voltage drops with each process generation to save power, VOH, VOL, VIH, and VIL all move closer together, and the noise margins that used to be generous get tight.

D

Mixed-signal and noisy environments raise the stakes

Digital logic sitting next to analog circuitry, power switching, or long off-chip traces needs wider margins than an isolated digital block ever would.
